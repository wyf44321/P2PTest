## 2. 客户端实现

### 2.1 技术架构

客户端使用 Flutter/Dart 实现跨平台 App，状态管理采用 Provider 模式。无后端服务器，所有逻辑（包括 P2P 通信和 STUN）在客户端纯 Dart 层完成。

**核心依赖**：

| 功能 | 包 | 说明 |
|-----|---|------|
| 状态管理 | `provider` / `riverpod` | 响应式状态管理 |
| UDP 通信 | `dart:io` (`RawDatagramSocket`) | 纯 Dart UDP 打洞和消息收发 |
| STUN 客户端 | `dart:io` + 自实现 STUN 协议 | 纯 Dart 实现 STUN Binding Request |
| IP 归属地 | `http` | 通过 IP 查询 API 获取归属地信息 |
| 本地存储 | `shared_preferences` / `hive` | 监听用户列表持久化 |
| UI 组件 | `flutter/material` | Material Design |

## 3. P2P 连接实现

### 3.1 纯 Dart UDP 方案

采用 Dart 原生 `RawDatagramSocket` 实现 UDP P2P 通信，无需依赖原生桥接或第三方 P2P 框架。

**优点**：
- 纯 Dart 实现，无需 Platform Channel 桥接
- 轻量、包体积小
- 开发和调试简单

**缺点**：
- 需要自行实现 STUN 协议和打洞逻辑
- 不支持可靠传输（对 Ping/Pong 测量场景足够）

### 3.2 UDP 服务层

```dart
class UdpService {
  RawDatagramSocket? _socket;
  final Map<String, InternetAddress> _peerAddrs = {};
  final Map<String, int> _peerPorts = {};
  UdpEventListener? _listener;

  Future<int> bind({int port = 0}) async {
    _socket = await RawDatagramSocket.bind(InternetAddress.anyIPv4, port);
    _socket!.listen(_onData);
    return _socket!.port;
  }

  void _onData(RawSocketEvent event) {
    if (event != RawSocketEvent.read) return;
    final datagram = _socket?.receive();
    if (datagram == null) return;

    final data = utf8.decode(datagram.data);
    final msg = jsonDecode(data) as Map<String, dynamic>;
    final addr = '${datagram.address.address}:${datagram.port}';
    _listener?.onMessage(addr, msg['type'], msg);
  }

  void sendMessage(String ip, int port, String type, Map<String, dynamic> data) {
    final msg = jsonEncode({...data, 'type': type});
    final bytes = utf8.encode(msg);
    _socket?.send(bytes, InternetAddress(ip), port);
  }

  void setEventListener(UdpEventListener listener) {
    _listener = listener;
  }

  void close() {
    _socket?.close();
    _socket = null;
  }
}

abstract class UdpEventListener {
  void onMessage(String remoteAddr, String msgType, Map<String, dynamic> data);
}
```

#### 3.4.3 UDP 打洞流程

```
用户A                          STUN 服务器                         用户B
  │                                │                                │
  │── STUN Binding Request ───────►│                                │
  │◄── 公网地址A ─────────────────│                                │
  │                                │                                │
  │                                │◄── STUN Binding Request ──────│
  │                                │── 公网地址B ──────────────────►│
  │                                │                                │
  │   (用户A手动输入用户B的公网地址)                                    │
  │                                                                 │
  │══════════════ UDP hole punching ══════════════════════════════►│
  │◄═══════════════════════════════════════════════════════════════│
  │                                                                 │
  │                   UDP 直连建立                                   │
```

双方同时向对方的公网地址发送 UDP 包，利用 NAT 映射规则实现穿透：

```dart
Future<bool> holePunch(String remoteIp, int remotePort, {int timeoutSec = 10}) async {
  final deadline = DateTime.now().add(Duration(seconds: timeoutSec));
  bool connected = false;

  // 持续发送打洞包，直到收到对端响应或超时
  while (!connected && DateTime.now().isBefore(deadline)) {
    sendMessage(remoteIp, remotePort, 'punch', {
      'timestamp': DateTime.now().millisecondsSinceEpoch,
    });
    await Future.delayed(const Duration(milliseconds: 500));
  }
  return connected;
}
```

## 4. 连接监控实现

### 4.1 轮询探测机制

采用轮询（Round-Robin）方式，每秒依次探测一个监听用户，向其发送 Ping 并更新连接状态。N 个用户时，每个用户的有效探测间隔为 N 秒。

重连失败后的用户降级为每 1 分钟探测一次，由独立的降级定时器管理。

```dart
class MonitorService {
  final UdpService udpService;
  final Map<String, PingStats> _peerStats = {};
  Timer? _probeTimer;
  Timer? _statsTimer;
  final Map<String, Timer> _degradedTimers = {};
  int _currentIndex = 0;

  void startMonitoring(String peerId) {
    _peerStats[peerId] = PingStats();
  }

  void startTimers() {
    _probeTimer = Timer.periodic(Duration(seconds: 1), (_) {
      _probeNextPeer();
    });

    _statsTimer = Timer.periodic(Duration(seconds: 5), (_) {
      _calculatePacketLoss();
    });
  }

  void _probeNextPeer() {
    final connectedPeers = _getConnectedPeers();
    if (connectedPeers.isEmpty) return;

    _currentIndex = _currentIndex % connectedPeers.length;
    final peer = connectedPeers[_currentIndex];
    _sendPing(peer);
    _currentIndex++;
  }

  void _sendPing(MonitoredPeer peer) {
    final seq = _nextSeq++;
    final timestamp = DateTime.now().millisecondsSinceEpoch;

    udpService.sendMessage(peer.ip, peer.port, 'ping', {
      'seq': seq,
      'timestamp': timestamp,
    });

    _peerStats[peer.id]?.recordPingSent(seq, timestamp);
  }

  void onPongReceived(String peerId, int seq, int pingTimestamp) {
    final now = DateTime.now().millisecondsSinceEpoch;
    final rtt = now - pingTimestamp;
    _peerStats[peerId]?.recordPongReceived(seq, rtt);
    peerProvider.updateRTT(peerId, rtt);

    if (peerProvider.getPeerStatus(peerId) == ConnectionStatus.degradedMonitoring) {
      _cancelDegradedTimer(peerId);
      peerProvider.updatePeerStatus(peerId, ConnectionStatus.connected);
      startMonitoring(peerId);
    }
  }

  void startDegradedMonitoring(String peerId) {
    _degradedTimers[peerId]?.cancel();
    _degradedTimers[peerId] = Timer.periodic(Duration(minutes: 1), (_) {
      final peer = peerProvider.getPeer(peerId);
      if (peer != null) _sendPing(peer);
    });
    peerProvider.updatePeerStatus(peerId, ConnectionStatus.degradedMonitoring);
  }

  void _cancelDegradedTimer(String peerId) {
    _degradedTimers[peerId]?.cancel();
    _degradedTimers.remove(peerId);
  }

  void stopMonitoring(String peerId) {
    _peerStats.remove(peerId);
    _cancelDegradedTimer(peerId);
  }

  void clearDisconnectedPeers() {
    final toRemove = peerProvider.peers
        .where((p) => p.status == ConnectionStatus.disconnected ||
                      p.status == ConnectionStatus.degradedMonitoring)
        .map((p) => p.id)
        .toList();

    for (final peerId in toRemove) {
      stopMonitoring(peerId);
      peerProvider.removePeer(peerId);
    }
  }
}
```

### 4.3 丢包率计算

```dart
class PingStats {
  static const int windowSize = 30;
  static const int pongTimeoutMs = 3000;

  final Queue<PingRecord> _pingHistory = Queue();

  void recordPingSent(int seq, int timestamp) {
    _pingHistory.addLast(PingRecord(seq: seq, sentAt: timestamp));
    while (_pingHistory.length > windowSize) {
      _pingHistory.removeFirst();
    }
  }

  void recordPongReceived(int seq, int rtt) {
    for (final record in _pingHistory) {
      if (record.seq == seq) {
        record.rtt = rtt;
        record.received = true;
        break;
      }
    }
  }

  double calculatePacketLoss() {
    if (_pingHistory.isEmpty) return 0.0;
    final now = DateTime.now().millisecondsSinceEpoch;
    int lost = 0;
    int total = 0;
    for (final record in _pingHistory) {
      if (now - record.sentAt > pongTimeoutMs) {
        total++;
        if (!record.received) lost++;
      }
    }
    if (total == 0) return 0.0;
    return (lost / total) * 100.0;
  }
}
```

## 5. 断线重连实现

### 5.1 重连策略

```dart
class ReconnectStrategy {
  static const List<Duration> intervals = [
    Duration(seconds: 1),
    Duration(seconds: 5),
    Duration(seconds: 10),
    Duration(seconds: 30),
    Duration(seconds: 60),
  ];
  static const int maxAttempts = 5;
}
```

### 5.2 重连控制器

```dart
class ReconnectController {
  int _attempt = 0;
  Timer? _timer;
  bool _isReconnecting = false;

  final Future<bool> Function() onReconnect;
  final VoidCallback onSuccess;
  final VoidCallback onFailure;
  final void Function(int attempt, int maxAttempts) onAttemptUpdate;

  ReconnectController({
    required this.onReconnect,
    required this.onSuccess,
    required this.onFailure,
    required this.onAttemptUpdate,
  });

  void start() {
    if (_isReconnecting) return;
    _isReconnecting = true;
    _attempt = 0;
    _scheduleNext();
  }

  void _scheduleNext() {
    if (_attempt >= ReconnectStrategy.maxAttempts) {
      _isReconnecting = false;
      onFailure();
      return;
    }
    final delay = ReconnectStrategy.intervals[_attempt];
    _timer = Timer(delay, () async {
      _attempt++;
      onAttemptUpdate(_attempt, ReconnectStrategy.maxAttempts);
      final success = await onReconnect();
      if (success) {
        _isReconnecting = false;
        onSuccess();
      } else {
        _scheduleNext();
      }
    });
  }

  void cancel() {
    _timer?.cancel();
    _isReconnecting = false;
    _attempt = 0;
  }
}
```

### 5.3 断线检测与处理

```dart
void _handlePeerDisconnected(String peerId) {
  peerProvider.updatePeerStatus(peerId, ConnectionStatus.reconnecting);

  final peer = peerProvider.getPeer(peerId);

    },
  );

  controller.start();
}
```

## 6. IP 归属地查询实现

### 6.1 查询服务

使用 IP 归属地查询 API 获取 IP 的地理位置和运营商信息，查询结果缓存到内存。

```dart
class IpGeoService {
  final Map<String, String> _cache = {};
  static const String _apiBase = 'http://ip-api.com/json';

  Future<String> queryLocation(String ip) async {
    if (_cache.containsKey(ip)) return _cache[ip]!;

    if (_isPrivateIp(ip)) {
      _cache[ip] = '内网地址';
      return _cache[ip]!;
    }

    try {
      final response = await http.get(
        Uri.parse('$_apiBase/$ip?lang=zh-CN&fields=status,country,regionName,city,isp'),
      );
      if (response.statusCode == 200) {
        final data = jsonDecode(response.body);
        if (data['status'] == 'success') {
          final location = '${data['city'] ?? data['regionName']}/${data['isp']}';
          _cache[ip] = location;
          return location;
        }
      }
      _cache[ip] = '未知';
      return '未知';
    } catch (e) {
      return '未知';
    }
  }

  bool _isPrivateIp(String ip) {
    final parts = ip.split('.').map(int.parse).toList();
    if (parts[0] == 10) return true;
    if (parts[0] == 172 && parts[1] >= 16 && parts[1] <= 31) return true;
    if (parts[0] == 192 && parts[1] == 168) return true;
    return false;
  }
}
```

- 查询完成后更新 PeerProvider，UI 自动刷新

## 7. 本地数据持久化

### 7.1 持久化方案

使用 `shared_preferences` 或 `hive` 存储监听用户列表和 STUN 服务器配置。

```dart
class StorageService {
  static const String _peersKey = 'monitored_peers';
  static const String _stunConfigKey = 'stun_config';

  // --- 监听用户持久化 ---

  Future<void> savePeers(List<MonitoredPeer> peers) async {
    final prefs = await SharedPreferences.getInstance();
    final data = peers.map((p) => p.toJson()).toList();
    await prefs.setString(_peersKey, jsonEncode(data));
  }

  Future<List<MonitoredPeer>> loadPeers() async {
    final prefs = await SharedPreferences.getInstance();
    final jsonStr = prefs.getString(_peersKey);
    if (jsonStr == null) return [];
    final list = jsonDecode(jsonStr) as List;
    return list.map((j) => MonitoredPeer.fromJson(j)).toList();
  }

  // --- STUN 服务器配置持久化 ---

  Future<void> saveStunConfig(StunConfig config) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString(_stunConfigKey, jsonEncode(config.toJson()));
  }

  Future<StunConfig?> loadStunConfig() async {
    final prefs = await SharedPreferences.getInstance();
    final jsonStr = prefs.getString(_stunConfigKey);
    if (jsonStr == null) return null;
    return StunConfig.fromJson(jsonDecode(jsonStr));
  }
}
```

### 7.2 持久化时机

- 添加用户后自动保存
- 删除用户后自动保存
- App 进入后台时保存
- 仅持久化 IP、端口、添加时间等静态信息，不保存运行时状态
- **STUN 配置**：用户选择/输入 STUN 服务器后立即保存

### 7.3 恢复逻辑

- App 启动时从本地加载 STUN 服务器配置（如有），优先使用用户记录的服务器获取公网地址
- App 启动时从本地加载已保存的监听用户列表
- 恢复到界面，所有用户初始状态为「连接中」
- 自动对每个用户发起 UDP 打洞连接
